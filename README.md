# 📚 Book Haven

A modern, responsive online bookstore built with HTML5, CSS3, and Bootstrap 5.

## 🌐 Live Demo

[https://abisenbeekk.github.io/web-assignment1-book-haven/](https://abisenbeekk.github.io/web-assignment1-book-haven/)

## ✨ Features

- **Fully Responsive** — Desktop, tablet, mobile
- **Bootstrap 5** — Grid system and components
- **Bootstrap Icons** — Beautiful icon library
- **Gradient Design** — Modern purple-pink theme
- **Smooth Animations** — Hover effects and transitions
- **5 Pages** — Home, Books, Genres, About, Contact

## 📄 Pages

| Page | Description |
|------|-------------|
| **Home** | Hero section, stats, featured books |
| **Books** | Book catalog with search |
| **Genres** | Browse books by genre |
| **About** | Developer profile and skills |
| **Contact** | Contact form and information |

## 🛠 Technologies

- HTML5
- CSS3 (Media Queries, Flexbox)
- Bootstrap 5.3
- Bootstrap Icons
- Git & GitHub Pages
